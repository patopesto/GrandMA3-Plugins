This is an unoffical reference documentation.  
This came as a need for a more complete and useful documentation whilst developing LUA plugins and more generally whilst using the grandMA3 platform.

The documentation for each version is generated using the [APIDump](https://github.com/patopesto/GrandMA3-Plugins/tree/master/APIDump) LUA plugin run in the `Simple_show` Demo showfile.
